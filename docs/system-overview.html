01 — Tầm nhìn sản phẩm

Công cụ cá nhân cho giáo viên, dữ liệu riêng theo từng tài khoản

English Path là công cụ cho giáo viên tiếng Anh THCS, kết hợp nội dung học tập và tiện ích hỗ trợ công việc giảng dạy. Bốn mục tiêu cốt lõi:

📚
Soạn & tra cứu nhanh

Bài học và từ vựng theo khối, tra cứu tức thì, ghi chú riêng theo chủ điểm.

🗂️
Quản lý công việc dạy học

Nhắc việc theo tuần, mẫu lặp lại và lịch dạy bù được theo dõi tập trung.

🎯
Tạo hoạt động luyện tập

Sinh quiz từ đoạn văn, luyện từ vựng và trò chơi nhẹ cho học sinh.

📱
Chuẩn bị source mobile

Source MOS được tách khỏi web và bảo lưu riêng để chuyển đổi cho mobile sau này.

Nguyên tắc: Nhẹ — chạy trên free tier Riêng tư — dữ liệu theo tài khoản Ưu tiên giáo viên dùng cá nhân

04 — Yêu cầu phi chức năng

Kiến trúc kỹ thuật & ràng buộc nền tảng

Ưu tiên nhẹ, an toàn theo tài khoản, và có khả năng suy biến khi thiếu backend.

⚛️ Frontend

  • React + Vite + TypeScript
  • Ant Design làm hệ UI
  • React Router — HashRouter cho GitHub Pages
  • Trang được lazy-load
  • i18n qua src/i18n.ts, mặc định tiếng Việt

🗄️ Backend

  • Supabase (Postgres + Auth + Edge Functions)
  • Chạy trên free tier
  • Đăng nhập qua GitHub OAuth
  • Edge Function tự sinh IPA + cache
  • Suy biến: isSupabaseConfigured khi thiếu env

🔒 Bảo mật

  • RLS bật cho mọi bảng dữ liệu người dùng
  • Chỉ dùng anon key ở frontend
  • Không đưa service role key vào client

🎨 Giao diện

  • Hỗ trợ light / dark mode
  • 3 cỡ chữ: sm / md / lg
  • Lưu tùy chọn ở localStorage
  • Responsive: topbar/sidebar thu gọn trên mobile

🧪 Kiểm thử

  • Logic thuần có unit test
  • planner/utils.test.ts
  • practice/utils.test.ts
  • Mở rộng độ phủ khi thêm logic

⚡ Hiệu năng & dữ liệu

  • Dữ liệu tĩnh tách khỏi dữ liệu người dùng
  • Nội dung tĩnh vẫn chạy khi không có backend
  • Tối ưu tải trang qua lazy-load
05 — Quy ước kiến trúc

Bắt buộc khi phát triển tiếp

Mỗi tính năng nằm trong 1 thư mục dưới src/pages theo mẫu ở src/pages/README.md: FeaturePage.tsx, components/, hooks/, utils.ts, types.ts, tùy chọn data.ts / storage.ts / pdf.ts.

Truy cập Supabase đi qua module dịch vụ theo domain trong src/lib/supabase — không rải query trong UI. teacherData.ts chỉ là barrel tương thích ngược.

Cần bảng/policy mới → thêm file .sql trong supabase/, bật RLS ngay từ đầu.

Chuỗi hiển thị đưa vào i18n; logic thuần tách khỏi JSX để test được.

06 — Lộ trình phát triển

Từ nền tảng giáo viên đến mở rộng cho học sinh

Giai đoạn 1 — Nền tảng giáo viên Hoàn thành phần lớn

  • ✓Đăng nhập GitHub + profiles
  • ✓Lessons + từ vựng giáo viên + IPA tự động
  • ✓Practice + lưu quiz/attempts
  • ✓Planner (repeat, PDF) + Make-up Schedule
  • ✓Office Tips / Playground
  • ✓Tách source MOS khỏi web và bảo lưu cho mobile

Giai đoạn 2 — Hoàn thiện & đồng bộ Kế tiếp

  • ◇Đồng bộ ghi chú Office từ localStorage lên Supabase
  • ✓Dùng một nguồn task chung cho Planner, Home và notification
  • ◇Thống kê kết quả Practice (biểu đồ, tỷ lệ đúng theo chủ điểm)
  • ◇Xuất dữ liệu (từ vựng, quiz) ra PDF/CSV
  • ◇Hoàn thiện trang Progress theo khối/lớp
  • ◇Tăng độ phủ unit test cho các module dịch vụ

Giai đoạn 3 — Mở rộng cho học sinh Tương lai

  • ◇Vai trò học sinh, giao quiz và thu bài
  • ◇Nâng browser reminder thành push notification khi web đóng
  • ◇Bảng xếp hạng / gamification cho Playground
  • ◇Tách quyền giáo viên / học sinh, nâng cấp hạ tầng khi tải cao
07 — Rủi ro & điểm cần theo dõi

Sáu điểm cần giám sát

⚠️ Ghi chú Office chỉ ở localStorage

Ghi chú mất khi đổi thiết bị hoặc xóa cache — cần đồng bộ nếu hỗ trợ đa thiết bị.

⚠️ Source MOS là snapshot

Source đã tách khỏi web nhưng vẫn dùng React/Ant Design; cần chuyển đổi khi kiến trúc mobile được xác định.

⚠️ Browser reminder phụ thuộc web đang mở

Planner, Home và notification đã dùng chung task state, nhưng chưa có server push khi website đóng.

⚠️ Nội dung là dữ liệu tĩnh

Bài học nằm trong code → cập nhật nội dung phải deploy lại toàn app.

⚠️ Phụ thuộc GitHub OAuth

Học sinh THCS có thể không có tài khoản GitHub → cân nhắc thêm provider khác khi mở cho học sinh.

⚠️ Giới hạn free tier Supabase

Theo dõi dung lượng / số row khi lượng user tăng lên để tránh vượt hạn mức.
